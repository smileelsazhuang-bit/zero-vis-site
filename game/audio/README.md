## 本轮 7 首的准备与技术验收

原始音频实际均为 90.044063 秒，先取 90 秒。检测未发现需要删除的尾部持续静音；将最后 3 秒与开头 3 秒做等功率交叉淡化，再接回主体，得到 87 秒循环。穹顶原始曲首较弱，初次环接出现约 0.81 秒极低电平；最终改用原始第 3–90 秒环接，得到 84 秒版本，检测不再出现该停顿。归一化目标为 -20 LUFS、-3.5 dBTP，并预留转码峰值余量。
