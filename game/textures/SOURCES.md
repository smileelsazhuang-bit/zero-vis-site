# 本地 PBR 纹理来源

所有纹理来自 Poly Haven 官方 API，按 CC0 1.0 Universal 提供；无须署名即可使用、修改和再分发。

- 许可说明：https://polyhaven.com/license
- CC0 法律文本：https://creativecommons.org/publicdomain/zero/1.0/
- 下载日期：2026-10-15
- 规格：1k JPG，漫反射、OpenGL 法线、粗糙度各一张；原始文件未修改，下载时校验官方 MD5 和文件大小。
- 本地加载，游戏运行时不访问 Poly Haven。

- [Rock Boulder Dry](https://polyhaven.com/a/rock_boulder_dry)；作者：Dimitrios Savva、Rico Cilliers
- [Bark Brown 02](https://polyhaven.com/a/bark_brown_02)；作者：Rob Tuytel
- [Brown Mud Leaves 01](https://polyhaven.com/a/brown_mud_leaves_01)；作者：Rob Tuytel
