# Rock Moss Set 01

Official unmodified 1K glTF package from
<https://polyhaven.com/a/rock_moss_set_01>. Creator: **Kless Gyzen**.

License: **CC0 1.0 Universal**. See the included `LICENSE-CC0.txt` and
<https://polyhaven.com/license>.

Downloaded 2026-10-16 from <https://api.polyhaven.com/files/rock_moss_set_01>.
All five package files match the official MD5 values in `source-manifest.json`.
Package size: **1,937,065 bytes**, six scanned rocks totaling **63,127 triangles**.

Three of the six original scans are reused as independent instanced batches,
with scale derived from their actual bounding boxes. The originals' diffuse,
OpenGL normal and roughness images remain unchanged; the lower portions are
buried slightly into the terrain to avoid a floating prop appearance.
