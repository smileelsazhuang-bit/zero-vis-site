# Fern 02

Official unmodified 1K glTF package from <https://polyhaven.com/a/fern_02>.
Creators: **Rob Tuytel** (scanning), **Rico Cilliers** (modeling).

License: **CC0 1.0 Universal**. The complete legal text is included as
`LICENSE-CC0.txt`; the provider statement is <https://polyhaven.com/license>.

Downloaded 2026-10-16 from <https://api.polyhaven.com/files/fern_02>. All five
package files match the official MD5 values recorded in `source-manifest.json`.
Package size: **1,146,361 bytes**, four fern variations totaling **6,232 triangles**.

The four original specimens are individually centered and grounded using their
actual geometry bounds, then reused with InstancedMesh at natural heights.
Original albedo, OpenGL normals and ARM textures are retained. Alpha-cutout foliage
is separately marked for the renderer's SSAO exclusion.
